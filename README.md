# 本月预算

一个自己在手机上用的记账工具：顶部大字显示「本周期每天最多还能花」，四张分类卡盯住吃饭/衣服/交通/生活弹性，底部有本月结余。数据存在自己的私有仓库里，手机和电脑打开同一个网址，内容自动同步。

- `docs/index.html` —— 页面本体，全部逻辑内嵌，无外部依赖（GitHub Pages 从这里发布）
- `worker.js` / `wrangler.jsonc` —— Cloudflare 版部署文件（备用，见文末）

---

## 一、打开网址

```
https://closeee.github.io/budget-tool/
```

第一次打开会让你填一个 **访问令牌**（GitHub Token）。填一次就记住了，之后不用再填。

### 怎么拿令牌

1. 电脑浏览器登录 GitHub → 右上角头像 → **Settings**
2. 左栏拉到最底 → **Developer settings**
3. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
4. 填名字（随意），**Expiration 建议选 No expiration**（否则到期要重来）
5. **Repository access** 选 *Only select repositories* → 勾上 **budget-data**
6. **Permissions** → Repository permissions → **Contents** 设为 **Read and write**
7. 点 Generate，复制那串 `github_pat_...`

把它填进网页的令牌框，点「连接」。手机和电脑各填一次。

> ⚠️ 这串令牌等于钥匙，别发给别人、别贴到聊天里。它只对 `budget-data` 这一个仓库有权限，即使泄露也动不了你的其他东西。

---

> **⚠️ 公司电脑上用不了，这是正常的。**
> 页面要带令牌去读 `api.github.com`，浏览器发令牌前必须先发一个 OPTIONS 预检请求，而公司网络封掉了 GitHub 系域名上的这类请求。手机上（流量 / 家里 WiFi）不受影响。
> 所以在公司电脑上打开会显示「同步失败，检查网络」——不是坏了，是网管挡的。记账都放手机上做。

## 二、日常使用

| 操作 | 说明 |
|---|---|
| 记一笔 | 选支出/收入 → 选类型 → 填金额 → 可写备注 → 点「记一笔」 |
| 记收入 | 收入分两种：**工资** 决定基数（录了就按你录的算，不录按 11,850 估）；**其他进账**（红包/报销/闲鱼等）不影响基数，直接加到可花额上 |
| 看进度 | 顶部「本周期每天最多还能花」，四张卡显示各大类剩余和进度条 |
| 看明细 | 切到「明细」页，按日期看每一笔，可筛 全部/支出/收入/各分类，手动记的可删 |
| 导账单 | 支付宝/微信导出 CSV → 点「导账单」上传 → 自动分类入库 |
| 断开连接 | 底部按钮，清掉本机保存的令牌 |

**工资周期**：每月 12 号发薪，周期为「本月 12 号 → 次月 12 号」，不是自然月。

**预算额度**：页面顶部把算式摊开了，可以逐项核对——

```
工资 11,850（没录就按这个估） − 储蓄 3,500 − 房租 2,200 + 其他进账 = 可花
可花 − 已花 = 剩 ÷ 剩余天数 = 每天还能花
```

三类固定：吃饭 1500 / 衣服 2000 / 交通 350；**生活弹性自动吸收剩下的**（卡片上直接标了 `额度 = 可花 − 三类固定 3,850`）。

要改这几个数，编辑 `docs/index.html` 顶部的 `BASE`、`SAVE`、`RENT`、`DEFAULT_PAY`、`PAY_DAY`。

**本月结余**：页面最底部，= 可花 − 已花（和顶部那个「剩」是同一个数）。到下个月 12 号周期切换后自动归零重算，**不结转**。

## 三、个人分类规则怎么改

同事姓名、一起吃饭的人、境外商户这些**没有写进代码**（这个仓库是公开的），而是存在私有的 `budget-data` 仓库 `data.json` 里的 `rules` 字段：

```json
{
  "rules": {
    "eat":    ["某人"],              // 和这个人一起吃的 → 记「吃饭」
    "skip":   ["同事甲", "同事乙"],   // 和这些人的人情往来 → 记「同事」，不计入预算
    "travel": ["okinawa", "香港"]     // 含这些词的 → 记「旅行」，不计入预算
  }
}
```

想加人，直接编辑 `budget-data` 仓库里的 `data.json` 即可，网页下次连接时自动读取。

## 四、账单从哪导出

- **支付宝**：App → 我的 → 账单 → 右上角 → 开具交易流水证明/导出 → 选 CSV
- **微信**：App → 我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 选「用于个人对账」 → CSV

> 上传的账单只在本机浏览器里解析分类，文件本身不会上传。只有解析出来的记录会存进你的 `budget-data` 仓库。

## 五、Cloudflare 版（备用，暂时没用）

`worker.js` + `wrangler.jsonc` 是另一条部署路子：密码门 + Durable Object 同步。公司网络对 `*.workers.dev` 的 HTTPS 做了拦截，所以没走这条。如果哪天 GitHub Pages 访问不了，可以用它：把 `wrangler.jsonc` 里的 `APP_PIN` 和 `AUTH_SECRET` 改成自己的值，然后 `npx wrangler deploy`。
